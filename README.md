# Projeto Integrador - Adoção e Resgate de Animais Comunitários (Tema 13)

Aplicação mobile desenvolvida para a disciplina de **Aplicações em Dispositivos Web / Móveis**.

## Status da Entrega (MVP - 1ª Tela Funcional)
* **Tela desenvolvida:** Cadastro de Animal para Adoção.
* **Tecnologias:** Kotlin, Jetpack Compose, Material Design 3.
* **Recursos Implementados:**
  * Componentes estruturais Compose (`Scaffold`, `Column`, `Row`).
  * Gerenciamento de Estado com `remember` e `mutableStateOf`.
  * Padrão **State Hoisting** (separação de telas Stateful e Stateless).
  * Campos de entrada de texto com validação visual simples.
